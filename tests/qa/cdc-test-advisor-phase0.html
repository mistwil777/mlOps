Prérequis

  • Stack Docker : docker-compose up -d
  • API backend : uvicorn api.main:app --port 8002
  • Frontend : cd frontend && npm run dev
  • Ouvrir http://localhost:5173/advisor
  • Le bloc "Phase 0 — Architecture mémoire" est visible en haut de page
Mode d'emploi : Pour chaque scénario, utilise le bouton Copier à droite de chaque champ, colle la valeur dans le formulaire, lance l'analyse, puis coche les cases si le résultat correspond.
